Hermes Desktop keeps the pane off until you turn it on. Open Capabilities, Plugins, and enable Kin. That switch is the host's own opt-in. There is no file to edit.

If the pane does not appear, use Rescan, then Reload desktop plugins.

The head ships inside desktop/plugin.js. You do not install Node packages, and you do not download the model.
